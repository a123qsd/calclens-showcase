Licenses & distribution

How you may use CalcLens, what the downloads contain, and what the app obtains during first-time setup.

CalcLens use terms

CalcLens is free for personal, academic, research and internal organizational use. You may publish or use your results and figures commercially. Free redistribution of the app requires its original license and notices. Selling the app and providing a paid hosted service require prior written permission.

Full CalcLens Free Internal Use License

Inside the public files

The public repository contains this website and screenshots. Releases carry the downloads. Both packages contain compiled CalcLens modules, a launcher, synthetic teaching CIFs, icons, fonts and notices. The Mac download also carries the single Qt Cocoa plugin described below. The Windows ZIP does not bundle Python, Qt or ASE runtimes. The executable bytecode can be inspected. The development repository and its commit history are private.

The Nanum Gothic font is accompanied by its copyright notice and the full SIL Open Font License 1.1. The release lists the files and SHA-256 digests for each platform. Public release

First launch

On first launch, choose Install to let the launcher obtain Python and the required libraries for this device. You do not need to install Python, Qt or ASE yourself. Setup requires internet access and disk space. Subsequent local review and computation work offline.

Python comes from Astral’s python-build-standalone release. Python packages come from PyPI. The launcher verifies pinned versions and SHA-256 digests. Molecular calculation features differ between Windows 0.11.1 and Mac 0.12.0. Python distribution · PyPI

Operating systems and signing

The Mac app requires Apple Silicon and macOS 15 or later. It is ad-hoc signed and has not been notarized by Apple. The Windows x64 launcher is unsigned. Your operating system may show a warning; verify the download source and the SHA-256 digest listed in the release.

Third-party components and replacement

Qt for Python and Shiboken offer LGPLv3 and alternative licenses. ASE uses LGPL-2.1-or-later and Paramiko uses LGPL-2.1. The app obtains these runtime libraries on the recipient’s device. Their installed distributions retain their version-specific notices and license texts.

To use a compatible modified library, install it in a separate Python environment and point CALCLENS_PYTHON to that interpreter before opening the app. The app license permits library replacement and debugging to support that replacement. Qt distribution guidance · ASE license

The Qt Cocoa plugin in the Mac download

The Mac package carries a Qt 6.12.0 Cocoa platform plugin built with upstream fix 8148c48d for a crash when accessibility services inspect table elements. The distribution was exercised on Apple Silicon. The plugin is supplied under LGPLv3, with copyright notices, full LGPLv3 and GPLv3 texts, and the BSD notice for the Apple Cocoa portions in the package.

The Mac release includes the corresponding source, applied patch and build instructions at no charge. Users may replace and debug a compatible modified plugin. The installed plugin is not overwritten on every launch. Corresponding source ZIP · Upstream Qt change

Mac calculation engines

Mac molecular calculations use RDKit (BSD-3-Clause), PySCF (Apache-2.0), geomeTRIC and tblite (LGPL-3.0-or-later). The engines are obtained during setup and run locally on the CPU. Each package’s notices and the terms for its additional components apply. RDKit · PySCF · geomeTRIC · tblite

Release inspection

Each platform artifact is reopened and compared with its approved file list and hashes. The public packages exclude plaintext application Python source, the legacy web bundle, full research logs, research datasets, personal paths, server profiles and keys. The site is published from this repository alone.

Earlier packages

Historical packages remain under license review. The review inventoried 105 assets across 13 releases and examined the original GA 0.11.0 Windows ZIP and Mac DMG in detail. Earlier releases received a limited inventory review. The earlier Windows package included additional GPL-covered Qt components.

Verified Qt 6.12.0, PySide/Shiboken 6.12.0, ASE 3.29.0 and NSIS 3.13 sources and notices have been prepared separately. These materials contain no CalcLens application source. They do not establish adequate source delivery at the time, correspondence for every old binary, or successful library replacement in the historical apps. Those questions and the obligations for earlier releases remain open. Earlier recipients retain their original license rights.
