Existing Mac validation
For Mac 0.17.1, 68 focused source tests, 68 compiled-package tests, five native Mac checks and an application launch passed. Native checks compare the selection interior in light and dark themes. For Mac 0.17.0, 207 compiled-package tests and 26 native app scenarios passed. The initial full source run and focused reruns after fixes cover 2,743 distinct passing cases and 5 skips; a second full source suite was not run after the fixes. The 0.13.0 Mac build was exercised on Apple Silicon with macOS 27.2. The 0.13.0 Windows x64 build was checked on hosted Windows with software OpenGL. Live laboratory Gaussian submissions need separate validation.
Windows validation
Built and run locally on physical Windows 11 with NVIDIA RTX 5060 Ti. The complete source run has 2,555 passes and 233 skips; compiled distribution-module tests have 946 passes and 221 skips. Tests requiring absent engines or other environments are excluded from pass counts. Korean/Japanese-path install, removal, reinstallation and user-file preservation were checked. A separate Windows 10 machine and live Gaussian/SSH server calculations were not verified. Validation details · Windows changes
Interpreting results
Compare force-field, xTB and DFT energies within their categories and compatible conditions. Initial-to-final energy changes describe that calculation. Optimizer convergence does not establish a global minimum; these local calculation paths do not compute thermal/Gibbs corrections or spin–orbit effects.
