CalcLens 이용 조건

CalcLens 0.13.1·0.13.2·0.14.0·0.15.0·0.15.1은 개인·교육·연구와 기관·기업 내부에서 무료로 사용하고 자체 수정할 수 있습니다. 계산 결과와 그림은 발표하거나 상업적으로 이용할 수 있습니다. 공식 설치 파일은 원본 그대로 무료로 다시 배포할 수 있습니다. 새 앱 소스나 수정본을 외부에 배포하려면 기존 권리로 이미 허용된 경우를 제외하고 사전 서면 허가가 필요합니다.

수정하지 않은 공식 앱은 무료 원격 서비스로 제공할 수 있습니다. 원격 이용 허락은 앱 소스나 다른 사본의 전달을 자동으로 허용하지 않습니다. 앱 판매와 유료 호스팅에도 별도 허가가 필요합니다. 이전 1.0 약관, 타사 라이선스 또는 법률에 따라 이미 가진 권리는 그대로 유지됩니다.

공개 파일에 포함되는 것

공개 저장소에는 이 사이트와 실제 앱 화면을 담았습니다. 다운로드는 별도 릴리스에 있습니다. 앱 패키지는 컴파일한 CalcLens 모듈, 실행기, 교육용 CIF, 아이콘과 글꼴을 담습니다. Mac에는 아래에 설명한 Qt Cocoa 플러그인 하나와 그 고지도 포함됩니다. Windows ZIP에는 Python이나 Qt·ASE 런타임을 동봉하지 않습니다. 컴파일된 네이티브 앱도 오프라인에서 분석하거나 역공학할 수 있습니다. Gaussian SSH 연결에는 연구실 서버에서 실행할 짧은 Python 도우미가 포함되며, 이 코드는 읽을 수 있습니다. 개발 저장소와 커밋 이력은 비공개입니다.

포함한 나눔고딕 글꼴에는 SIL Open Font License 1.1 전문과 저작권 고지를 동봉했습니다. 운영체제별 파일 목록과 SHA-256은 릴리스에서 확인할 수 있습니다. Mac 0.15.1 릴리스 · Windows 0.13.1 릴리스

처음 실행할 때

앱을 처음 열고 설치를 선택하면 실행기가 이 기기 전용 Python과 필요한 라이브러리를 내려받습니다. Qt·ASE나 Python을 하나씩 찾아 설치할 필요가 없습니다. 첫 설치에 인터넷 연결과 디스크 공간이 필요합니다. 설치 이후에는 구조 열기와 로컬 계산을 오프라인으로 사용할 수 있습니다.

Python은 Astral의 python-build-standalone 배포본에서, Python 패키지는 PyPI에서 받습니다. 실행기는 지정된 버전과 SHA-256을 확인합니다. Mac 0.15.1과 Windows 0.13.1은 구조 편집과 RDKit 역장 계산을 제공합니다. Mac 기본 설치는 추가 계산 엔진도 내려받습니다. Python 배포처 · PyPI

운영체제와 앱 서명

Mac은 Apple Silicon·macOS 15 이상용입니다. 앱은 ad-hoc 서명이며 Apple 공증을 받지 않았습니다. Windows x64 실행기는 서명되지 않았습니다. 운영체제가 경고를 표시할 수 있으니 다운로드 배포처와 릴리스의 SHA-256을 확인하세요.

제3자 구성요소와 교체

Cython 3.3.1은 앱을 만들 때 사용하는 도구이며, 별도의 Cython 컴파일러나 런타임은 배포본에 포함되지 않습니다. Cython의 COPYING.txt는 결과물에 포함된 Cython 코드 조각 때문에 추가 라이선스 제한이 생기지 않는다고 설명합니다.

Qt for Python과 Shiboken은 LGPLv3 또는 해당 대안 라이선스, ASE는 LGPL-2.1-or-later, Paramiko는 LGPL-2.1 조건을 제공합니다. 이 앱은 런타임을 사용자의 기기에서 가져옵니다. 설치한 패키지 안에서 해당 버전의 고지와 라이선스를 확인할 수 있습니다.

사용자는 호환되는 수정 라이브러리를 별도의 Python 환경에 설치하고 CALCLENS_PYTHON을 그 환경의 실행 파일로 지정해 CalcLens를 열 수 있습니다. 라이브러리 교체와 이에 필요한 디버깅은 앱 라이선스에서 허용합니다. Qt 배포 지침 · ASE 라이선스

Mac에 포함한 Qt Cocoa 플러그인

macOS가 표의 접근성 정보를 읽을 때 창이 종료되는 문제를 수정하기 위해, Qt 6.12.0 Cocoa 플랫폼 플러그인에 Qt의 공식 수정 8148c48d를 적용했습니다. Qt 플러그인은 Apple Silicon에서 사용하도록 빌드했습니다. 이 플러그인은 LGPLv3 조건으로 제공합니다. Mac 배포본에 저작권 고지, LGPLv3·GPLv3 전문과 Apple Cocoa 부분의 BSD 고지가 들어 있습니다.

플러그인의 전체 대응 소스, 적용한 패치와 빌드 지침을 Mac 배포본과 함께 무료로 제공합니다. 사용자는 호환되는 수정 플러그인으로 교체하고 디버깅할 수 있습니다. 기본 런타임에 설치된 플러그인은 이후 실행마다 다시 덮어쓰지 않습니다. 대응 소스 ZIP · Qt 원본 수정

0.15.0과 0.15.1은 0.14.0에서 검토한 Qt Cocoa 플러그인과 대응 소스를 변경하지 않고 사용합니다. 각 릴리스의 소스 ZIP은 같은 원본 묶음을 추가 주소로 제공하며, 이전 버전의 소스와 고지는 계속 보존합니다.

로컬 계산 엔진

두 운영체제의 기본 설치는 유한 분자용 RDKit(BSD-3-Clause)을 내려받아 로컬 CPU에서 실행합니다. Mac은 추가로 PySCF(Apache-2.0), geomeTRIC, tblite(LGPL-3.0-or-later)를 설치합니다. Windows 0.13.1의 기본 설치에는 이 세 패키지가 포함되지 않습니다. geomeTRIC과 각 엔진의 원문 고지 및 추가 구성요소의 조건은 해당 패키지에 적용됩니다. RDKit · PySCF · geomeTRIC · tblite

Qt 배포 자료 확인 결과

2026-11-08, Windows 0.11.0을 기준으로 공개된 Qt·PySide/Shiboken 소스와 빌드 자료, 라이선스 전문을 대조했습니다. 이 범위에서 더 제공해야 할 소스·빌드 자료의 누락이나 라이브러리 교체 권리의 제한은 발견하지 못했습니다. Mac 0.14.0에 함께 제공되는 Qt Cocoa 소스 묶음에도 수정 사항, 빌드 방법과 교체 안내가 들어 있습니다.

Windows 0.11.0 원본의 한국어·영어 화면에서 3D 렌더링, 그림 내보내기, Gaussian 작업공간과 프로젝트 재열기를 실행했습니다. 조사 대상 Qt DLL·플러그인 9개는 이 작업 동안 로드되지 않았습니다. 별도 대조 시험에서 9개를 일부러 로드하고 해제하자 모두 기록됐습니다. 이 결과는 시험한 동작과 버전에 한정됩니다.

과거 Windows 0.9.0~0.11.0에는 GPLv3 대상 Lottie·Quick Timeline과 Qt GPL 예외가 붙은 QmlCompiler가 포함됐습니다. 0.11.0 Mac·Windows에서 빠져 있던 LGPL 전문은 아래 보완 자료에서 받을 수 있습니다. 원본 소스 묶음의 작성 당시 고지는 보존하며, 이후 확인 결과는 이 페이지와 검토 기록에 반영했습니다.

Windows 0.11.0은 Qt/PySide 6.12.0을 6.11.3으로 대체한 뒤 3D·Gaussian 작업 검사를 통과했습니다. Mac 0.11.0 복사본은 수정한 Qt Cocoa 플러그인을 실제로 로드했습니다. 앱 약관은 LGPL 라이브러리의 수정·교체와 필요한 디버깅을 허용합니다.

초기 Windows 지원 ZIP 여섯 개에는 ASE 3.29.0 소스가 있고, 0.8.0 영어판은 동봉 안내에 따라 수정 ASE를 넣어 다시 빌드한 뒤 자체 검사를 통과했습니다. 0.11.1 Windows 전체 런타임의 Paramiko 파일 42개도 공식 5.1.0 소스와 일치했습니다.
