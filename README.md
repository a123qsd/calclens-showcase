# CalcLens Showcase

macOS 1.2.3 corrects atom-centered fitting and rotation pivots, preserves the last camera pose when gestures end through focus, mode or window-size changes, and restores the starting pose on Esc. It updates transparent atom labels, overlap priorities, the fixed-size orientation marker, periodic-image identity and cancelled edit previews. Double-click bond-order edits are limited to Draw and Bond modes. The bilingual site uses byte-for-byte native Cocoa captures of the final validation source and labels its five-atom validation scene explicitly. Windows remains at 0.17.1; the development repository remains private.

The source validation includes 648 passes and one skip before the last preview adjustment, then 124 impacted passes, 52 harness passes and 150 automated native Cocoa passes. These sets overlap and are not added together. In the recorded asymmetric and translated scenes, fixed atom-fit-center drift fell from about 228 px and 204 px to 0 px. Saved-state notifications and status refreshes each fell from 72 to 3 over three full-window camera gestures; recovery saves stayed at 3. Input-to-VTK-render latency results were mixed. Physical mouse/trackpad input, mixed-scaling display transfers, long-term memory stability and final display latency were not measured. See the [screenshots and scope](https://a123qsd.github.io/calclens-showcase/guide-en.html#viewport-1-2-3).

Windows 0.17.1 includes cumulative editing, interchange and Gaussian workflows from the Mac 0.17.1 source baseline. Mac 0.17.1 fixes the opaque drag selection rectangle: a theme-colored border leaves atoms and bonds visible inside it. Light and dark pixel comparisons verify the interior stays unchanged. The focused source suite passes 68 tests; the compiled package passes 68 tests and five native Mac checks.

Mac 0.17.0 prepares Gaussian jobs from the current structure and reads observations from imported outputs: HOMO/LUMO and electron density, relaxed bond/angle/dihedral PES scans, PBC single-point and optimization inputs, transition-state optimization with frequencies, IRC, SCF stability, TD-DFT and NMR shielding. The user selects method, basis, charge and multiplicity. Each exported job has a unique folder ID; orbital postprocessing supports the appropriate single or alpha/beta recipes without overwriting existing outputs. Results appear in tables and plots; table rows link to their sources and CSV exports include source-line numbers. Missing values in incomplete or malformed output are not inferred, and source-line references are preserved when large files are read using streaming. PES summary energy offsets and IRC path segmentation are handled as well. Restoring a draft preserves in-progress numeric text, including invalid values, and the inspector remains scrollable in narrow windows.

Gaussian must run separately on a configured server; saving a job does not run it. A live Gaussian server calculation was not verified for this release. PBC support prepares Gaussian inputs with one to three selected Tv vectors and does not add local periodic or GPU DFT. TS validity and IRC endpoints are not automatically certified. NMR shielding is not a chemical shift without a reference.

Mac 0.16.0 extends Gaussian input and external file exchange. Use **Open files** in the main toolbar to select a structure, input or result. Gaussian route examples, memory, core, `%CPU` and `%LindaWorkers` settings can be reviewed before export. From a CHK, prepare a `formchk` command to create an FCHK, then prepare `cubegen` HOMO/LUMO commands using that FCHK; an existing FCHK can be used directly. An imported FCHK or Cube can also be saved unchanged. For a Cube with multiple orbitals, choose the dataset to display explicitly.

The Mac release supports 13 structure import formats, with format-specific export limits shown on the website. It prepares finite-molecule inputs and optional Slurm/PBS script examples for ORCA, Q-Chem, NWChem DFT, Psi4 and xTB. Enter each program’s method and basis in its own notation. These external programs and Gaussian utilities require separate installation; saving a bundle does not run or submit a calculation.

Mac 0.15.1 strengthens ECP/basis checks and revalidates convergence at the final optimization geometry. It preserves edits made during calculations and saved result views, and rejects invalid Gaussian form values before export. Windows 0.17.1 includes these shared workflow improvements, while its default native engines remain RDKit UFF and MMFF94s; PySCF and tblite are not provided by the Windows runtime.

Mac 0.15.0 introduced the shared Auto recommend menu, per-atom UFF/MMFF preflight, geometry/electronic-method suggestions and explicit before/after energy displays. Comparisons retain energy categories, calculation conditions and compatibility limits. Opening recommendations does not run a calculation or transfer or move SSH files.
