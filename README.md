# CalcLens Showcase

CalcLens is a desktop workbench for inspecting crystals, molecular structures and calculation results. This repository contains the bilingual portfolio, screenshots and application licenses, including the 0.13.1, 0.13.2, 0.14.0, 0.15.0 and 0.15.1 terms and the preserved version 1.0 terms. Download Apple Silicon Mac 0.15.1 or Windows x64 0.13.1 from Releases. The application development repository is private.

[한국어](https://a123qsd.github.io/calclens-showcase/) · [English](https://a123qsd.github.io/calclens-showcase/en.html) · [Licenses and distribution](https://a123qsd.github.io/calclens-showcase/licenses-en.html) · [Releases](https://github.com/a123qsd/calclens-showcase/releases)

Mac 0.15.1 strengthens ECP/basis checks and revalidates convergence at the final optimization geometry. It preserves edits made during calculations and saved result views, and rejects invalid Gaussian form values before export. Windows remains at 0.13.1.

Mac 0.15.0 introduced the shared Auto recommend menu, per-atom UFF/MMFF preflight, geometry/electronic-method suggestions and explicit before/after energy displays. Comparisons retain energy categories, calculation conditions and compatibility limits. Opening recommendations does not run a calculation or transfer or move SSH files. [Illustrative graphene screenshot from 0.15.0](assets/auto-recommend-0.15.0.png)

The Mac 0.15.1 release provides the [DMG](https://github.com/a123qsd/calclens-showcase/releases/download/v0.15.1/CalcLens-0.15.1-macOS-Apple-Silicon.dmg), [file inventory](https://github.com/a123qsd/calclens-showcase/releases/download/v0.15.1/CalcLens-0.15.1-macOS-files.json), [SHA-256 checksums](https://github.com/a123qsd/calclens-showcase/releases/download/v0.15.1/SHA256SUMS.txt), [release verification](https://github.com/a123qsd/calclens-showcase/releases/download/v0.15.1/release-verification.json) and [Qt Cocoa corresponding source](https://github.com/a123qsd/calclens-showcase/releases/download/v0.15.1/CalcLens-0.15.1-Qt-Cocoa-source.zip). This source ZIP is the unchanged reviewed 0.14.0 archive under an additional release link; prior source archives and license rights remain available.

The site publishes only the files in PUBLIC-FILES.txt. Each release lists SHA-256 checksums for the application packages. The source archive generated by GitHub contains this showcase.
