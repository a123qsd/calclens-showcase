# CalcLens Showcase

CalcLens is a desktop workbench for inspecting crystals, molecular structures and calculation results. This repository contains the bilingual portfolio, screenshots and application licenses, including the 0.13.1, 0.13.2, 0.14.0, 0.15.0, 0.15.1 and 0.16.0 terms and the preserved version 1.0 terms. Download Apple Silicon Mac 0.16.0 or Windows x64 0.13.1 from Releases. The application development repository is private.

[한국어](https://a123qsd.github.io/calclens-showcase/) · [English](https://a123qsd.github.io/calclens-showcase/en.html) · [Licenses and distribution](https://a123qsd.github.io/calclens-showcase/licenses-en.html) · [Releases](https://github.com/a123qsd/calclens-showcase/releases)

Mac 0.16.0 extends Gaussian input and external file exchange. Use **Open files** in the main toolbar to select a structure, input or result. Gaussian route examples, memory, core, `%CPU` and `%LindaWorkers` settings can be reviewed before export. From a CHK, prepare a `formchk` command to create an FCHK, then prepare `cubegen` HOMO/LUMO commands using that FCHK; an existing FCHK can be used directly. An imported FCHK or Cube can also be saved unchanged. For a Cube with multiple orbitals, choose the dataset to display explicitly.

The Mac release supports 13 structure import formats, with format-specific export limits shown on the website. It prepares finite-molecule inputs and optional Slurm/PBS script examples for ORCA, Q-Chem, NWChem DFT, Psi4 and xTB. Enter each program’s method and basis in its own notation. These external programs and Gaussian utilities require separate installation; saving a bundle does not run or submit a calculation.

Mac 0.15.1 strengthens ECP/basis checks and revalidates convergence at the final optimization geometry. It preserves edits made during calculations and saved result views, and rejects invalid Gaussian form values before export. Windows remains at 0.13.1.

Mac 0.15.0 introduced the shared Auto recommend menu, per-atom UFF/MMFF preflight, geometry/electronic-method suggestions and explicit before/after energy displays. Comparisons retain energy categories, calculation conditions and compatibility limits. Opening recommendations does not run a calculation or transfer or move SSH files.
