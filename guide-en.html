Why CalcLens?

A short distance in a CIF only makes sense once you know which atoms and cell images it connects. A Gaussian energy value is easier to interpret when you can find the geometry that produced it.

CalcLens keeps the selected atoms, coordinates and source lines together. Reopening a project restores the structures and calculation conditions you were reviewing.

macOS 1.3.0
Console, files and results

Resize the console, change file locations and inspect connection states or Gaussian results alongside the structure. Existing documents, calculation drafts and sessions remain in the same workspace.

Choosing a file location does not connect a shell or submit a research-server job. Connection, disconnection and job execution each use their explicit actions.

macOS 1.3.0

Resize the console directly

Drag the 7 px divider, or maximize, restore and hide the console. The normal panel size, structure camera, logs and SSH session are retained. A console explicitly resized by the user keeps that state when the window becomes shorter.

macOS 1.3.0

A lobby with actual connection states

The selected server, a checked login and an active terminal connection are distinct. Connect and Disconnect follow the current shell state. Choosing a server profile or file location does not open a shell.

macOS 1.3.0

Remote terminal and keyboard focus

The bottom terminal is for remote SSH and does not run a local shell. Its empty state opens the connection lobby. Tab moves to other controls while disconnected, and closed-session output remains copyable.

macOS 1.3.0

One file-location selector

Switch between the current project, a local folder and server files while retaining their models and selections. Header menus hold examples and secondary actions. Short panels scroll to keep lower actions reachable.

macOS 1.3.0

Fit atoms or the whole cell

Fit atoms centers the atoms; Fit cell includes the lattice, vacuum and atoms. Both preserve view direction, and a label identifies the current fitting target. R and direction presets reset orientation. Narrow headers wrap, while elided filenames and status text retain full tooltips.

macOS 1.3.0

Gaussian results and source excerpts

Open Gaussian results or use Command+Shift+G for .log/.out files. Inspect the selected job step's reported status, energy, convergence and frequencies, then expand the source excerpt. Source-row tables and exports remain available. Missing quantities and empty filters have distinct guidance.

.log/.out files are calculation results; .gjf/.com are calculation inputs. FCHK/Cube open in electronic analysis, and general Open files can also import their atomic geometry into the editor. Unreported values are unknown, not zero. Normal termination does not establish stability or optimization convergence.

macOS 1.2.3
Keep the atoms in view

Fitting a small structure to a large cell could leave the atoms tiny and off to one side. The default fit and rotation pivot now use the atoms, with separate fits for the cell, selection and measurements.

These native macOS captures show the same five-atom validation scene at the same orientation. The standalone viewport is 800 × 560 logical pixels at DPR 2, using the English interface.

1.2.2 · Cell-centered fit

The cell's empty space determined the fit, with a rotation pivot away from the atom center.

1.2.3 · Atom-centered fit

Fit uses the atom bounds and preserves orientation. R also resets the orientation.

Changes to interaction and display

  • Camera gestures keep the last pose when focus, mode or window size changes. Esc restores the gesture's starting pose. Opening an optimization result preserves the latest camera pose.
  • Labels have transparent backgrounds and a screen gap from each sphere. Measurements, selection and hover have priority; some ordinary labels may be hidden in dense scenes. The orientation marker keeps a 96 × 96 logical-pixel area.
  • Cancelled orange previews are cleared across mode, document and focus changes. Stored bonds, CIF distance guides, measurements and temporary previews have distinct meanings; intentional distance guides remain visible.
  • Double-click bond-order edits are limited to Draw and Bond modes. Periodic images retain both atom ID and cell shift, and invisible move handles do not capture a click.
Measured scope and remaining checks

The validation source ran on macOS Apple Silicon with Python 3.12.16, PySide6 6.12.0 and VTK 9.7.2. The integrated offscreen run passed 648 tests with one skip. After the final preview adjustment, 124 impacted tests, 52 input-replay harness tests and 150 automated native Cocoa checks passed in separate runs. These sets overlap and are not added together.

In the asymmetric scene and its translated copy, maximum screen drift of the fixed atom-fit center fell from about 228 px and 204 px to 0 px in each case. Across three camera gestures in the full window, saved-state notifications and status refreshes each fell from 72 to 3; recovery saves remained at 3.

Input-to-VTK-render latency increased in some scenes and decreased in others. These results do not establish an overall FPS improvement. Physical mouse and trackpad behavior, transfers between displays with different scaling, long-term memory stability and final display latency were not measured.

What can you do with CalcLens?

Mac 1.3.0 and Windows 0.17.1 provide structure editing, recommendations and preflight, energy comparisons, file interchange and advanced Gaussian preparation and analysis. The default Windows engines are RDKit UFF and MMFF94s. PySCF and GFN2-xTB are not included in the default Windows environment.

macOS 1.3.0

Local/server files and diagnostics

Choose the current project, a local folder or server files in one location selector, and inspect current-task diagnostics in the bottom Problems tab. Keep the structure viewer, inspector, terminal, jobs and logs in the same window.

Mac · Windows

CIF structures & periodic distances

Open a CIF, repeat its cell and select atoms to measure distances, angles and dihedrals. Inspect the neighboring cell and shift behind a short periodic distance, along with layer thickness and gaps.

Mac · Windows

Projects & structure comparison

Save structure-specific settings and notes, then reopen your work. Check the atom mapping before comparing molecular RMSD or periodic displacement in the same cell.

Mac · Windows

Gaussian output review

Inspect optimization steps, SCF energies, vibrational modes and IR intensities. Follow a selected result to its source line and coordinates, then prepare a follow-up input from that structure.

Mac · Windows

Gaussian inputs & server jobs

Set charge, multiplicity and calculation conditions to prepare an input and job folder. With an SSH profile and lab-specific commands, submit jobs and check their status. Gaussian runs on a separate server.

Mac · Windows

Charge & electron density

Import external charge JSON and Cube data for display with a structure. Inspect planar averages and cumulative electron counts from the first total-density block of a supported VASP CHGCAR.

Mac · Windows

Figures & result exports

Save structure and density-profile figures as PNG or PDF, with source and display settings recorded alongside them. Export result tables to CSV.

Mac 1.3.0 · Windows 0.17.1

Edit in the same workspace

Select, move or add atoms while inspecting CIF structures and molecules in the 3D view. Edit bonds and coordinates, and undo changes.

Mac 1.3.0 · Windows 0.17.1 · Experimental

Small-molecule CPU calculations

Both default installations provide RDKit MMFF94s and UFF force fields for finite molecules. Mac also provides GFN2-xTB and PySCF DFT. For periodic structures, first select atoms to form a finite cluster. Periodic and GPU DFT are outside the supported scope.

Mac 1.3.0 · Windows 0.17.1

Context recommendations & per-atom preflight

Auto recommend offers next steps for selected atoms, periodic structures, results and server screens. UFF and MMFF94s check the actual bond graph and charges, identifying unsupported elements, atom numbers and types where RDKit can locate them. Apply a method suggestion, then start a calculation separately.

Mac 1.3.0 · Windows 0.17.1

Before / after energies & comparison conditions

Inspect saved input and output geometries together with initial and final energies and ΔE. Force-field, xTB and DFT energies retain their categories. Incompatible conditions show a reason instead of a ranking. Verified pairs of UKS optimizations can show an adiabatic spin gap.

Mac 1.3.0 · Windows 0.17.1

Structure and calculation input exchange

Review support for 13 structure formats and prepare input and run bundles for ORCA, Q-Chem, NWChem DFT, Psi4 and xTB. These external programs require separate installation; saving a bundle does not start a calculation.

Mac 1.3.0 · Windows 0.17.1

Gaussian routes and orbital files

Enter Gaussian route examples, memory, cores and server nodes. Prepare FCHK conversion and HOMO/LUMO Cube commands from a real checkpoint, and select a dataset when a Cube contains multiple orbitals.

Submission to a live laboratory Gaussian server has not yet been verified. Interpret results in the context of their inputs and calculation conditions.

Mac 1.3.0 · Windows 0.17.1
Gaussian inputs and results

Prepare calculation-specific inputs from the current structure, then import logs, checkpoint and Cube files to inspect recorded results. You choose the method, basis, charge and multiplicity.

Gaussian runs separately on a laboratory server where it is installed. Saving an input or job folder does not start a calculation. A live Gaussian server run was not verified for this release.

01 · HOMO / LUMO

Orbitals and electron density

Inspect orbital energies from a log or FCHK and isosurfaces from Cube files. The job folder includes formchk and cubegen postprocessing instructions. Select the single-orbital or separate α/β recipe to match the calculation; existing outputs are not overwritten.

02 · PES SCAN

Bond, angle and dihedral scans

Prepare a relaxed scan that changes a bond length, angle or dihedral while optimizing the remaining geometry. The result shows completed points and energies recorded in the output.

03 · PBC

Periodic energy and optimization

Export the lattice vectors of the one to three active periodic axes as Tv for a Gaussian single-point energy or geometry optimization. This prepares server-side Gaussian inputs; it does not introduce local periodic or GPU DFT.

04 · TRANSITION STATE

Transition state and frequencies

Prepare Opt=(TS,CalcFC) Freq and inspect imaginary frequencies and modes in the output. One imaginary frequency alone does not establish the intended transition state.

05 · IRC

Reaction path

Prepare an IRC input and inspect the directions, reaction coordinates and energies recorded in the output. The endpoints are not automatically certified as the intended reactant and product.

06 · STABILITY

SCF stability

Prepare Stable=Opt and inspect stable or unstable messages in the output. Stability and SCF convergence are shown separately.

07 · TD-DFT

Excited states

Set TD-DFT options such as the number of states and inspect excitation energies, wavelengths and oscillator strengths recorded in the output.

08 · NMR

Magnetic shielding

Prepare NMR input and inspect shielding constants for individual atoms. Chemical shifts require a separate reference value.

Choose the job name, title and checkpoint name, review the proposed input and log filenames, then export a new job folder. Each export receives a unique job ID even when the name is reused. Inspect results in tables and plots, follow a table row to its source, and export a CSV containing source-line numbers. Missing values in incomplete or malformed output are not inferred. Source-line references are preserved when large files are read using streaming. PES summary energy offsets and IRC path segmentation are handled as well.

Restoring a previous draft preserves numeric text still being edited, including invalid values. In a narrow window, the inspector scrolls to keep calculations and tools accessible.

Prepare input for another calculation program

Choose a structure with Open files in the main toolbar or File → Open molecular geometry…. View the Open files screen.

Use File → Input for other calculation apps… to prepare finite-molecule inputs and commands for ORCA, Q-Chem, NWChem DFT, Psi4 and xTB. Enter each program’s own method and basis names. Save the input, run script, settings record and optional Slurm or PBS submission example together for review.

External calculation programs require separate installation. Saving a bundle starts no calculation or server submission. The multi-node template distributes cores evenly for NWChem; adapt other allocations and launch settings to your site.

Continue with Gaussian inputs and orbital files

Apply and edit either Gaussian route example: #p B3LYP/6-31G(d) Opt SCF=XQC or #p APFD/6-311+G(2d,p) Opt Freq. Set memory, core count, %CPU and server nodes via %LindaWorkers. Choose either %NProcShared or %CPU; the Linda core setting applies to each worker.

Prepare a formchk conversion from an existing CHK and cubegen 0 MO=HOMO and cubegen 0 MO=LUMO commands from a CHK or FCHK. Run the commands separately where Gaussian is installed. Save an imported FCHK or Cube unchanged, and explicitly choose which dataset to display when a Cube contains multiple orbitals.

Find the next step for the current task

Auto recommend follows the active structure and selection. It leads to atom measurements, finite-cluster preparation, geometry or electronic-method review and result comparisons. Use Command+Shift+R on Mac. Opening the menu starts no calculation and does not transfer or move server files.

Structure format support

These 13 formats are available on Mac 0.17.1. Review the information-loss warnings shown after export. Save a CalcLens project or .atomic.json too when atom IDs, constraints, electronic state and provenance must be retained.

Import and export

  • XYZ (.xyz) — atoms and coordinates for finite structures.
  • Extended XYZ (.extxyz) — cell and partial periodicity. Extended XYZ content in .xyz is also imported. Charge and multiplicity use CalcLens-specific metadata that other apps may not read.
  • CIF P1 (.cif) — explicit, fully occupied atoms and cell. Export requires three periodic axes.
  • PDB (.pdb) — coordinates and a representable cell. Resolve alternate locations and partial occupancies before import.
  • MOL V2000 (.mol) — explicit bond orders, formal charges and isotopes for one molecule.
  • SDF V2000 (.sdf) — the same supported structure information for one molecule. Extra data and stereochemistry are not retained.
  • VASP POSCAR/CONTCAR (.vasp, .poscar) — periodic structures with explicit elements. Export requires three periodic axes.
  • XSF (.xsf) — atoms and supported periodic cells. Scalar grids and forces are not imported.
  • ORCA input (.inp) — imports inline Cartesian atoms, charge and multiplicity, and exports a geometry block. Prepare a complete calculation input separately.

Primarily import

  • MOL2 (.mol2) — atoms and bonds from a supported single molecule. Partial charges and atom types are not retained.
  • Gaussian input (.gjf, .com) — imports supported explicit Cartesian geometry. Complete Gaussian input can be prepared or preserved in its input screen.
  • Gaussian FCHK (.fchk, .fch) — reads geometry and supported fields from an existing file. Save the original or prepare a formchk command in the separate checkpoint screen.
  • Quantum ESPRESSO (.pwi, .in) — imports atoms and cell from ibrav=0 input. Pseudopotentials and spin settings are not imported.

For shared extensions such as .inp and .in, choose the input format. In Mac 1.3.0, general Open files can open FCHK and Cube in the 3D editor or the field-analysis screen; explicitly choosing the field-file filter opens analysis. Open molecular geometry… opens atomic geometry in the editor. Geometry can also be sent from analysis to the editor. Editor documents do not include FCHK wavefunction or orbital data, or Cube volume data. The reported blank viewport did not reproduce with the available samples, and its cause remains unverified. In Windows 0.17.1, choose a Cube with Open files or Open molecular geometry… to open it in the field-analysis screen. For supported Cube files, the display limits are 32 MiB, 1 million grid points and 4 million scalar values in total; atom and dataset counts are also limited. Use the server file browser to download checksum-verified originals above these limits for use in another app.
